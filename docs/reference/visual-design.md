# Wugweb Visual Design System

Version: 2.0

Purpose

This document defines how every visual asset for Wugweb should be designed.

This includes

• Presentations
• Posters
• Social media
• Landing pages
• Website graphics
• AI generated artwork
• Infographics
• Diagrams
• Motion graphics
• Product visuals
• Conference materials
• Marketing collateral

This document is the single source of truth.

Never invent a new visual language.

Every asset must look like it belongs to the Wugweb ecosystem.

---

# Wugweb Philosophy

Design is communication.

Everything decorative must also have a purpose.

The design should feel inevitable.

Nothing should exist simply because it looks nice.

Every element must explain, reinforce or simplify an idea.

# Design Principles

Hierarchy beats decoration.

Whitespace beats graphics.

Typography beats illustration.

Ideas beat effects.

Consistency beats originality.

Systems beat aesthetics.

---

# Primary Visual Language

Every composition should contain

One hero

One supporting element

One focal area

Nothing else.

Never have three competing focal points.

---

# Layout System

Primary layouts

50 / 50 split

40 / 60 split

Editorial column

Magazine spread

Hero + sidebar

Full bleed typography

Stacked content

Never random placement.

---

# Composition

Use

clear reading direction

visual rhythm

balanced asymmetry

large negative space

strong alignment

consistent baselines

Avoid

crowded layouts

visual noise

---

# Typography Philosophy

Typography IS the artwork.

If an illustration can be removed without losing meaning

remove it.

Large type creates hierarchy.

Small type supports hierarchy.

---

# Typography Rules

Hero text

Very large

Extra bold

High contrast

Often spans multiple lines.

Supporting copy

Maximum 60–75 characters per line.

Never justify text.

Always left align.

---

# Font Personality

Neo-grotesk

Neutral

Editorial

Modern

Rounded enough to feel human

Never geometric display fonts.

Never condensed.

Never futuristic.

---

# Color Philosophy

Color is used for emphasis.

Not decoration.

# Core Palette

#111111

White

#FFFFFF

Light Grey

#F5F5F5

Accent Yellow

#FFC52E

---

# Contrast Rules

High contrast.

Dark text on light.

Light text on dark.

Avoid medium grey text.

Avoid low contrast.

---

# Accent Usage

Yellow only communicates

highlight

emphasis

interaction

energy

Never use yellow for backgrounds across entire layouts.

Never use multiple accent colours.

# Quality Checklist

Before approving

□ Could Apple publish this?

□ Could Stripe publish this?

□ Would this still look good in black and white?

□ Is there one clear message?

□ Is whitespace doing work?

□ Can anything be removed?

□ Is typography carrying the design?

□ Does it look premium?

If not

Regenerate.
